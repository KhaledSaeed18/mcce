# Security Policy

## Supported Versions

This project ships as a single rolling deployment from the `main` branch. Only the version currently deployed to production receives security fixes. There are no maintained past releases.

| Version | Supported |
| --- | --- |
| `main` (latest) | Supported |
| Older commits | Not supported |

## Reporting a Vulnerability

If you find a security vulnerability, report it privately rather than opening a public issue.

- Email contact@khaledsaeed.tech with a description of the issue, steps to reproduce, and any relevant logs or proof of concept.
- You can expect an initial response within 5 business days.
- If the vulnerability is confirmed, a fix will be prioritized and you will be notified once it is deployed. If it is declined, you will receive an explanation.
- Please do not disclose the issue publicly until a fix has shipped.
